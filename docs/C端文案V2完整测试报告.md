# 九盈英才 C端文案 V2 完整测试报告

> 历史资料。下文的“当前”“本轮”及验收数字均指报告出具时的版本。现行范围及验收进度见[项目文档索引](README.md)。

这是 V3.3 前序 C 端文案 V2 的历史专项报告。下文的测试数、工具记录和验包摘要归属该次交付。全量整改候选的测试证据见 [V3.3 当前发布状态](V3.3当前发布状态.md)。

## 工作范围

以已验包的 V3.3 完整源包为基线。原稿的 18 个页面逐页核对，并纳入 V3.3 新增的「业务详情」。变更范围为小程序文案、状态投影、必要的信息呈现与其回归测试。后端状态、审批、权限、财务算法、数据库迁移保持原实现。

## 本轮验证

- 基线 Node 回归 226 项通过。改稿后工作副本 Node 回归 241 项通过。最终解压包的总数、逐项原始日志和校验记录以 ZIP 同目录的验包摘要为准。
- 新增状态歧义、未知码、错误投影、月报提交取消与确认、网点及财务深链、生产构建清理和主要页面投影测试。旧测试继续核对后端状态、权限和数据。仅更新明确替换的文案断言及增加微信原生确认框的测试替身。
- 官方 wcc、wcsc 通过 19 页。开发构建和生产形态构建分别检查，生产包中的开发身份、测试短信和模拟支付控件应物理剥离。
- CLI 使用原有测试号尝试打开本版，工具提示服务端口关闭。当前版未在微信模拟器实际交互、未在真机实测。Chrome 回归用于总部 Web 和接口路径，不作为小程序截图或模拟器证据。
- 独立解压后校验文件 SHA256，重跑依赖安装、语法、迁移重复运行、Node、浏览器、原生静态与官方编译。测试使用隔离库，未执行生产数据迁移或真实资金交易。

## 人工验证路径

使用已授权测试号及隔离后端，依次打开登录、工作台、网点与详情、月报列表与编辑、服务费、申请、位置、客服、看板、消息、个人中心、财务、协议、待办、集团服务、业务详情与账号安全。重点点击月报提交取消、已审核旧版本、账单和退款通知、公开栏目撤回后的历史链接，并检查访客与加盟商的展示差异。
