## 如何核对任务状态

- **计划中。** 分级代理、Logo 修订及分级服务仍在[待办](../TODO.md)。旧记录中尚待明确或开发的网点转让、多月分摊、工作时段 SLA 和平台扩展继续在[待决规则](PENDING_DECISIONS.md)及[需求追溯](handoff/06-需求编号追溯.md)跟踪。
- **已实现，继续验收。** 工单图片、网点选店、月报样板、首次激活和品牌发布已有实现。独立人员逐页签收、真机、正式渠道和目标环境演练仍作为开发待办保留。
- **合并、隐藏或一期范围外。** 合并及隐藏项按[需求追溯](handoff/06-需求编号追溯.md)说明当前入口与保留能力。独立 APP、独立支付宝端和新抽佣按一期范围裁定保留历史记录。
