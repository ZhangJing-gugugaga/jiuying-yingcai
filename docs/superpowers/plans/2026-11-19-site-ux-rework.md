# 九盈英才全站体验重整实施规则

基线 `1e148854773fbff33c38477437c73a79ab9d3084`。以小程序 app.json 注册的 20 页为验收清单，另核对总部审批、培训、客服和财务的衔接。保留 V3.4.4 的业务范围。发布工程、真实模拟器操作与直接接口验证各自留存证据。

## 页面规则

| 主题 | 统一规则 |
| --- | --- |
| 公众与加盟商 | 公众首页可看集团介绍、五大业务、网点和地图，明显呈现加盟商登录。已登录首页呈现待办和常用业务。账号状态切换使用现有会话和授权。 |
| 导航与返回 | 从业务列表、消息、待办进入具体记录时带上网点、账期或月份和记录编号。使用已验证的原业务路由，返回保留来源筛选，失效和越权都有清楚反馈。状态更新时间按服务端。 |
| 网点和业务对象 | 读取汇总可用全部网点。写入时多网点用户从通用入口明确选择，来自指定记录的入口显示已确认的对象。使用真实网点 ID 提交。展示时用名称和地区帮助区分同名网点，指定对象失效需提示或重选。 |
| 列表 | 先显示标题及主入口，再显示常用筛选。记录卡以名称、月份或更新时间、状态和具体动作作首屏内容。辅助筛选、较长说明和历史信息可打开查看。 |
| 详情 | 首屏显示所属对象、当前状态、可用动作。有退回时先显示实际原因与补件入口。原始历史与审批信息按权限查看。 |
| 表单与结果 | 表单顶部明确对象，提交按钮使用具体动词。等待态限制重复提交，错误邻近操作，成功显示结果与下一步。保留未保存的输入和已选资料，切换前提醒。 |
| 视觉 | 复用现有蓝色品牌色、浅蓝底与白卡片，正文 28rpx、辅助信息 24–26rpx、普通页面标题约 44rpx。常用字号、圆角、边界和间距使用全局样式。主动作使用实色按钮，次操作使用描边或链接。支持窄屏、长标题和长地址换行。 |

## 文件所有权

- A 负责 login、profile、security、discover、service-detail、outlets、outlet。网点列表和详情同时覆盖公众和私有分支。首页的 A 建议交由 B 合并。
- B 负责 home、reports、report、messages、tasks。首页是 B 的唯一写入文件组。
- C 负责 training 和总部 admin-web/training.js。
- D 负责 support、requests、location。总部本轮走现有承接入口。
- E 负责 fees、finance、agreements、dashboard 和独立的 admin-web/billing-ledger.js。
- 主 Agent 负责 miniprogram/app.wxss、共享导航与格式化、交付、测试编排和跨页面问题。修改总部共享文件需要协调。

## 验收条件

1. 访客查看境外地址，返回后以隔离账号登录进入工作台。
2. 三网点负责人按退回待办打开原网点和月份，查看原因，保存并重进，重提后产生正确待审核版本。
3. 培训负责人从通知打开原学员，补交资料，总部审核，返回同一条记录看结果。
4. 普通咨询主动转工单后可查处理进度，相关网点和客服权限一致。
5. 停业申请可打开，其后的停费申请属于同网点的独立记录，分别由现有流程审批。
6. 20 页逐页记录实际打开、按钮、回退与视觉。提供实际截图和请求编号。未能操作的页面标出具体原因。
7. 全量 Node、总部 Chrome、官方页面编译、独立解压文件 SHA256 通过。验证使用隔离数据库与测试环境。
