# 总部网站问题复核

> 历史资料。下文的“当前”“本轮”及验收数字均指报告出具时的版本。现行范围及验收进度见[项目文档索引](README.md)。

本次以总部运营、财务与加盟商测试角色检查经营总览及经营月报，以浏览器可见状态、源码和回归区分已复现问题与待确认事项。

| 优先度 | 确认的问题 | 本轮处理 |
| --- | --- | --- |
| 高 | 财务账号可看到普通待审月报的审核按钮，实际接口只允许运营、管理层或获专项授权的区域运营。运营也会看到财务阶段按钮。 | 审核按钮按岗位和阶段显示，区域还须在授权网点及审核范围内。已增加浏览器回归复现财务错误入口。 |
| 中 | 月报筛选被插入第一张审核卡，列表顶部和底部重复分页。状态筛选还出现支付、客服、网点状态。 | 独立放到列表前，仅保留待审核、财务复核中、已退回、已通过，保留一套分页。 |
| 中 | 首次报送展示空白“本次变更对照”。 | 仅当字段存在差异才展示。 |
| 中 | 提示固定写 1–5 日和 6–10 日，系统实际支持总部配置报送截止日，页面无法证明固定审核期。 | 统一改为按总部公布的期限，网页逐张显示服务端记录的截止日。逾期与审批算法沿用现有规则。 |

下列事项需产品或制度决定，不影响两次本地 V1 审核结果。

1. **待办口径。** 总览把待审核和待修改合成一个数字。待修改通常归加盟商，财务复核则归财务。上线前需决定总览分别展示哪些计数，以及能否直接按责任人进入待处理列表。
2. **审批历史。** 总部当前可展开原始结构化审计。日常审核更适合按时间展示岗位、动作、意见和版本，原始记录可保留给审计。需确认区域岗位看哪些字段。
3. **报送和审核制度。** 报送截止时刻、节假日顺延、审核时限、含税与跨月退款归属需正式确认。已通过月报何时进入正式统计仍由总部结算制度决定。
4. **总览加载。** 浏览器一次进入总览会加载当前、同比、环比与六个月趋势。需用正式网络及数据量评估是否合并请求，当前仅有本地验证。

本轮网站聚焦总部月报及相邻入口，真实部署、真机和集团网络下的可用性与容量仍待验证。
