# 项目定位与一期功能范围

九盈英才统一服务集团的公开展示、加盟商网点运营协作及总部管理。公众用小程序发现服务，加盟商用小程序或受限 Web 办理网点事项，总部在 Web 审批、发布、处理客服和结算。双方使用同一业务记录与接口。三方的操作权限见 [三方关系与权限明细](handoff/02-三方关系与权限明细.md)。

现行实现以 V3.4.4 四入口源码及[页面结构](PAGE-STRUCTURE.md)为准，V4.1 保留为历史交接基线。历史需求讨论基线保留业务背景和集团待定事项。独立 APP、独立支付宝小程序、新抽佣模式按现行范围保留在候选库。既有培训记录保留与原业务连通，独立一期培训范围待集团确认。 [历史需求基线](handoff/历史需求依据/02_当前有效需求基线.md) · [一期范围收缩执行包](../docs/superpowers/plans/2026-11-20-phase-one-scope.md)

2026-11-25 分级代理报送已进入下一轮计划。计划覆盖总部绑定、一级进度与催报、二级经营月报和分级协议，当前功能目录描述已实现能力。详见[开发计划](../TODO.md#下一轮分级代理报送)。

## 2. 功能目录

| 模块 | 用户侧功能 | 管理侧功能 | 关键数据和产出 |
| --- | --- | --- | --- |
| 集团与公众 | 首页、集团介绍、已发布五大业务及详情、动态案例、公开网点列表及地图、合作与咨询 | 上传素材、编辑草稿、发布或撤回、维护公开网点与资料、受理合作 | 对外可见内容版本、公开地址/坐标、合作留言处理状态 |
| 账号与身份 | 首次激活、密码登录、可用时微信/短信登录、账号安全、负责人/手机号变更申请 | 创建主体及负责人、签发单次激活、冻结停用、换绑、员工岗位授权与交接 | `subject`、岗位、会话有效期、绑定版本、变更审计 |
| 网点档案 | 我的网点、状态与历史，申请新增、变更地点或经营状态 | 按审批生成档案、确认营业或状态变更、维护公开投影、批量导入预览及提交 | 一个主体多个网点、状态时间线、位置历史、档案编号 |
| 月报与免报 | 选网点与月份、存草稿、报送、补报、退回重提、原记录更正、查历史 | 运营初审、收入变更财务复核、例外免报、撤销复核、结算 | 草稿、提交版本、当前有效版、免报、结算快照 |
| 位置核验 | 选择网点和月份、主动获取 GPS、上传现场照片、保存地址/说明、查看异常及补件 | 位置专岗核验月度材料及新增/变更地址资料，确认或维护内部基准 | 坐标来源、精度、采集时间、现场资料、状态及证据权限 |
| 业务申请 | 按类型提交，查看进度，原单补件、办理后看结果 | 按申请类型交给运营、财务、位置专岗或管理层，写明结论和可公开说明 | 申请 ID、类型、网点/主体、前后值、状态、已创建档案或调整 |
| 服务费与协议 | 看账单、协议、历史与实收凭证，可用时支付，登记线下回单、按实收申请退款或开票 | 维护价格版本/协议，出账、对账、补账审核、费用核算和独立复核、冲正 | 应收、支付订单、实收、退款、票据、抵扣及服务期各自有记录 |
| 经营看板 | 查看本人网点月/季/年指标、趋势、比较及允许导出 | 总部看授权范围；管理层查四项分别排名、全集团统计、统一结算、发起汇总调整 | 过程数据、正式结算数据、数据覆盖率、历史调整、XLSX/PDF |
| 我的事项与消息 | 看待处理、处理中或历史，读通知并跳到原单 | 汇总运营待审核、财务复核、加盟商待修改、总部跟进；配置个人分派及监控逾期 | 事项对象、当前责任、截止/完成时间、通知已读状态 |
| 客服与投诉 | 找 FAQ、普通咨询、主动转人工、授权情况下拨工作电话、提交正式工单与补件、查状态及评价 | 接单、回复、补件、协作、严重投诉升级和关闭，管理 FAQ、电话、时间和导向 | 聊天与工单分别建档，内部备注、脱敏通知、处理历史、公众号下行投递状态 |
| 培训历史 | 通过既有入口查课程、本人网点学员、资料、进度和补件 | 管理既有课程发布、资料审核、授权范围与历史 | 课程、学员记录、私有附件、处理过程 |
| 审计与运维 | 只查看依法并适合其业务身份公开的历史摘要 | 操作审计、审批原始记录、个人分派与导出审计、定时作业、健康及备份校验 | 请求编号、个人账号、岗位、对象、时间、动作、原因及结果 |

业务状态、数据约束与验收详见[完整规格](handoff/01-完整需求与功能设计.md)。
