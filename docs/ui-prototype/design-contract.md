# 四张原型的设计取舍

目标是让访客在首页找到业务、网点和加盟入口，让加盟商知道当前在处理哪家网点的哪笔业务。此文面向产品、设计、原生小程序开发、总部 Web 开发和测试。以下“图示”来自用户提供的效果图，“现状”来自提交 `b131f07`，“建议”是本轮的实施默认值，可用对照样张复核。

| --- | --- | --- | --- |

### 页面冲突与实施决定

| 问题 | 现状与实施决定 | 对应需求 / 验收 |
| --- | --- | --- |
| 图 1 未绘底栏，图 2 使用“消息”，总览图使用“客服” | 采用现行角色底栏。访客为首页、网点、我的，加盟商为工作台、网点、月报、我的。客服从联系总部或业务入口进入，待办与通知从我的事项进入。 | 01、03、14、38 / A01、A04 |
| 登录、申请加盟与合作咨询容易混同 | 登录条面向已合作负责人。访客在首页可直接发起加盟申请，申请待补时可从通知回原单；合作咨询进入留言流程。加盟商切回公众视图有返回工作台入口。 | 09、10、C04、C05 / A01、A07 |
| 选择网点后任务中仍出现其他网点 | 建议初始显示“全部授权网点”，显式选定单店后才显示其营业状态。先证实待办计数、预览及目的页支持同一范围；如暂不支持，显示“全部授权网点”只读摘要，不提供会误导的切换器。 | 02、13、14 / A03、A04 |
| 工作台现有四入口，原型六入口 | 优先保留我的网点、经营月报、咨询服务费、我的事项的可达性。客服复用已有页；培训补件只开放给有权办理的已有记录，“更多业务”按来源进入停业申请、停费申请、位置核验。后两类申请各走原流程。 | 13、24、32、39、历史培训 / A04、A09 |
| 首页要展示跨业务历史 | “最近业务记录／查看全部记录”按授权网点展示月报、客服工单和培训记录，保留业务发生时间、状态和原单入口。已完成事项与通知沿用各自入口。 | 14、15、42 / A04 |
| 图示的“6 位激活码”“8–20 位密码” | 保留服务端签发的一次性令牌。密码采用现行 12–128 位和两次一致校验。激活码及两个密码字段可独立显隐，键盘按顺序移动，提交错误定位到对应字段。注册、付款、首次激活各保留独立入口和状态。 | 10、11、C04、C05 / A07 |

### 素材交付

原图已原样归档在本目录的 references 下，供对照评审。首页与工作台使用按原型生成的[城市插画](../../miniprogram/assets/home-skyline.webp)，首页地域入口使用[地图底纹](../../miniprogram/assets/home-coverage.webp)。两幅图均为装饰素材。正式标识、集团照片和联系渠道仍使用有发布依据的资料。业务缺图用图标，集团缺图转为纯文字，联系渠道未发布时省略该项。样张里的姓名、网点、金额、待办计数和状态全部使用隔离样本复现。
