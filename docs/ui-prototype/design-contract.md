11 月 26 日补充的[新版图册](../attachments/README.md#新版图册与现行功能)包含四类角色的 180 张页面状态图。按同角色、同状态比较图册和现有应用，本页保留四图中已经明确的入口、权限及字段取舍。图册里的登录条位置、导航或栏目差异进入对照验收。

本页保留原型与原实现基线的比较。工作台授权选店、历史记录、公众目录和关键表单的实际完成情况见[任务状态](../../TODO.md#四图原型任务状态)及[验收记录](acceptance.md)。

### 素材交付

原图已原样归档在本目录的 references 下，供对照评审。首页与工作台使用按原型生成的[城市插画](../../miniprogram/assets/home-skyline.webp)，首页地域入口使用[地图底纹](../../miniprogram/assets/home-coverage.webp)。两幅图均为装饰素材。正式标识、集团照片和联系渠道仍使用有发布依据的资料。业务缺图用图标，集团缺图转为纯文字，联系渠道未发布时省略该项。样张里的姓名、网点、金额、待办计数和状态全部使用隔离样本复现。

总部管理从「公开内容维护 → 集团品牌标识」发布同一份标识至访客首页和加盟商工作台。草稿沿用当前公开版本，撤回、缺图或加载失败时两个页面以「九」字标显示。

总部管理在「公开内容维护」分别发布「官方微信」和「总部地址」。首页查看微信二维码时重新检查发布状态。总部地址卡显示地区，点开后可复制详细地址。热线沿用总部客服设置。

公开店照由总部管理或运营在「知识与公开资料 → 公开网点」独立上传。档案发布且网点未关闭时，照片显示在公众目录、公开详情及加盟商本人的网点卡片。撤回档案、关闭网点或移除照片会撤销对应公开访问。目录中缺图或加载失败时显示门店图标（B07、B09、B11、H09）。

图 3 的「我的网点」状态筛选数量按当前账号授权、搜索词和地区计算，覆盖全部分页。显示有匹配记录的状态，并保留当前选择及「全部」。选中的状态没有匹配记录时显示 0。
