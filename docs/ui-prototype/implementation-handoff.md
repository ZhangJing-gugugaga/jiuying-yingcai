## 交付依赖

设计交付两幅首页的布局与裁切，给出长名称、缺图和大字号示例；素材责任方确认可发布的标识、照片、热线、地址与官方微信。[素材使用与缺省处理](design-contract.md)

前端复用原生组件、现有 TDesign 登记项和共享样式。现有工作台已经接入授权选店和跨业务历史。继续扩展时对齐接口的授权范围、分页总数、业务时间与目标 ID。若需要新接口，在服务端落实授权，完成双主体与同岗分派验收。[组件输入、状态与事件](../COMPONENT-GUIDELINES.md)

## 本机原型预览

按[项目 README](../../README.md#本地启动)启动后端，在微信开发者工具打开同一个 `miniprogram/`。改完在原项目点「编译」，从首页或工作台操作受影响的场景。需要特定网点、账期或退回原单时，在本地隔离库准备对应样本。

## 复验

按[验收单](acceptance.md)选测，用同一宽度比较原型和页面。跨端场景使用同一隔离库，核对原单与结果。首次运行或切换配置后，检查 API 地址及第一条相关业务请求。
