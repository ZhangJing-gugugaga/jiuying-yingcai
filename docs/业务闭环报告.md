**复核入口。** 本地总部 Web 使用开发角色。完成开户、发激活码、进入同一测试主体。小程序模拟器仅用隔离测试后端。先验证部分草稿、退回及结算，再验证位置拒绝与补传、客服升级和已读与工作事项的区别。支付测试只走 Mock 或本地协议替身，核对 SQLite 中的应收和实收。

复核细节、实际命令和限制见同包《业务复核》《权限复核》《原生链路复核》。上线制度依据 V3.1 第 19 节及已有上线资料清单。

V3 候选版的 T06 证据见 [历史月报闭环模拟器复验](月报闭环模拟器复验.md)。株洲 B 和长沙 A 的十月 V1 都完成草稿恢复、提交、总部运营审核和原生有效版本核对。
