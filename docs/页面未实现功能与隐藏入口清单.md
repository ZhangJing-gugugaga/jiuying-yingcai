# 页面未实现功能与隐藏入口清单

> 历史资料。下文的“当前”“本轮”及验收数字均指报告出具时的版本。查阅 [V4.1 交接说明](handoff/00-开发交接总说明.md)了解现行范围及验收进度。

以 V3.3 的真实接口为准。页面保持已有业务逻辑，待办、支付和授权仍由服务端判断。

| 页面 | 条件与实际呈现 |
| --- | --- |
| 登录 | 微信和手机验证码以平台能力返回值显示。未开放时提示改用账号登录。激活码已由总部绑定账号，现有激活接口提交激活码和密码。开发身份、测试短信仅开发构建保留。 |
| 工作台 | 网点总数和负责人来自授权数据。账单待办缺可用金额时不显示金额。只显示本人任务。 |
| 我的网点 | 列表、状态、搜索和已公开地图可用。网点列表没有位置、月报及账单统一摘要；详细数据要进入对应页面。公众使用独立权限投影。 |
| 网点详情 | 页内读取授权网点与当前经营数据。负责人查看实际地址和联系电话；公众使用已发布地址。没有已授权的总部公开电话时不展示。 |
| 经营月报列表 | 状态按现有提交、草稿、免报、待办数据呈现。仅在当前范围可核实时显示具体版本。大范围列表未读取到某网点的全部版本时，在详情核对当前及最近版本。 |
| 经营月报填写与详情 | 尚未开放、整月暂停和已免报按服务器资格显示。未确认的截止日期不展示。提交前用户确认，保留草稿和原有锁版规则。 |
| 咨询服务费 | 微信正式支付仅在配置启用时显示可用入口。支付宝接口现为手机网站收银台，微信原生页不开放真实支付宝入口。两种模拟支付只保留于开发构建。 |
| 业务申请 | 申请表单保留后台已支持的类型及字段。变更负责人或手机号沿用同一申请，仍需提供两项资料。缺自由申请和通用附件写入时不展示对应输入。 |
| 网点位置核验 | 位置仅主动获取，手动选点用于地址辅助。只有具备已确认偏差规则结果时才显示距离。 |
| 客服中心 | 总部电话和服务时间未配置时给出中性提示。正式工单只提供已支持的投诉、售后问题、经营异常。工单图片/通用附件未接入，保留文本补充入口。评价使用后台支持的满意度。 |
| 经营看板 | 仅展示已授权的数据。未完成审核或当期缺少统计时给出相应说明。同比、环比不可比时说明原因，不将缺失值当 0。 |
| 消息 | 通知有对应业务记录时提供查看详情。标为已读只更新消息。 |
| 我的 | 负责人、加盟商单位和管理网点来自账号授权数据。公开访客没有加盟商的私人入口。 |
| 付款与凭证 | 线下付款继续要求交易凭证编号，退款批准与退款完成分开，发票申请与已开票分开。无既有结构化付款方式或文件直传入口时，保留可提交的现行凭证字段。 |
| 服务协议 | 月度价格、服务、收款与开票主体从实际协议读出。正式方案缺生效期间不补造。协议服务期与已付使用期分开。 |
| 我的待办 | 仅显示本人授权任务并保留原有任务状态。截止日期存在且有效时显示。无对应业务的项目不显示去处理按钮。 |
| 集团介绍与服务 | 五个栏目仅展示已发布正文和图片，空栏目提示暂未发布。正式名称、集团素材、电话和方案依据集团资料。 |
| 账号安全 | 绑定微信仅在功能启用时显示。更换微信尚无独立操作，保留负责人和登记手机号的申请。 |
| 业务详情（V3.3） | 撤回或未发布版本显示暂不可查看，已发布内容和图片通过现有公开权限读取。 |

本轮无需新增数据库迁移或后端费用。正式验证需已有测试号运行环境，真实微信、公众号、支付、电话和集团资料仍按原上线资料清单准备。
