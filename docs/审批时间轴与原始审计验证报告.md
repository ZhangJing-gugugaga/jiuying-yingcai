# 审批时间轴与原始审计验证报告

> 历史资料。下文的“当前”“本轮”及验收数字均指报告出具时的版本。现行范围及验收进度见[项目文档索引](README.md)。

正式业务写入时保存关联对象、版本、操作者、角色、发生时间、动作、处理意见、相关字段快照、请求 ID 与可信来源。命令、公众号加密回调和内部作业分别记录其入口。时间轴和展开的原始记录复用同一个角色投影。月报可沿同主体、同网点与同期间查看真实历史版本。

| 检查 | 验证内容 |
| --- | --- |
| 真实性 | 月报提交、更正、退回、重提、收入财务复核、误审批撤销及原有效版逐事件核对。审批人使用实际操作身份。 |
| 不可变性 | 审批事件表阻止更新、删除与替换。角色只能读取已授权事件。命令写入失败与事务一起回滚。 |
| 历史兼容 | 旧报告与旧审计 JSON 保持原值。只用已有命令、留痕与协作记录生成时间轴。同毫秒的重复动作按存储顺序配对，未知字段留空。 |
| 分角色 | 管理层按职责检查；运营、财务、位置和客服仅查看对应业务；区域按有效授权网点和指标投影；加盟商仅见本人可公开摘要。财务内部撤销意见、原始账号 ID、请求关联和凭证按角色隐去。 |
| 敏感信息 | 不复制精确 GPS、完整附件内容与消费者联系方式到通用审批历史。对历史审计投影和新记录意见执行文本脱敏。 |
| 正式入口 | Web 展开从真实 HTTP 取得同源记录。公众号用本地签名样本验证不同消息及重放，服务费已确认抵扣在本地作业执行时记录实际应用。 |

复验使用 [审批事件测试](../backend/tests/v32-approval-history.test.cjs)。独立解压原始日志和交互截图可从 V3.2 测试证据（历史附件未随包提供，原路径 `../execution/V32_TEST_EVIDENCE.md`） 查看。正式平台凭证、真机和集团验收状态记录在 [上线资料清单](上线资料清单.md)。
