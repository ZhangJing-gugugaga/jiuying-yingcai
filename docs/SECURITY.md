# 安全与平台边界

权限按具体主体/资源/岗位/有效期校验。公众只读公开名称、地址、状态和授权publicLocation，不默认获得电话、精确GPS、财务、核验照片。加盟商只读本主体；总部运营/财务不默认获精确GPS和负责人换绑材料；位置专岗读核验所需；客服只读本人接单/必要消费者信息，默认无经营财务；区域逐人网点/指标/审核和有效期，排名及集团导出仅管理层。

本地scrypt密码、一次激活、失败限流和会话撤销保留。外部身份仅映射总部预建负责人；微信code由服务器换OpenID，身份HMAC索引、AES-GCM加密，客户端不得传角色升级。腾讯短信挑战5分钟/5次/单用/60秒重发，手机号和验证码不明文持久化；未知手机号不创建账户。换绑批准清旧密码/微信/激活/会话，历史归主体；负责人材料制度另需集团确认。

请求读取body、密码计算、图片解码、供应商返回等异步边界后重新校验会话，防止撤权窗口继续写入或获取结果。production禁开发登录/Mock；test/production原生包物理移除开发模块。PUBLIC_ORIGIN精确匹配，生产要求HTTPS；代理/IP/分布式限流仍须实际部署评估。

微信支付使用商户RSA签名、指定微信公钥ID验签与5分钟时间窗；原始回调验签后AES-GCM解密，核对App/商户/金额/币种/付款人、唯一渠道流水和通知摘要，事务一次入账。客户端success仅触发查单。未确认订单阻止冲正/线下重复收款。有限查单8次退避，异常及次数用尽留人工核实；过期且NOTPAY才关单，USERPAYING不直接关闭。无真实商户联调证明时不宣称生产安全验收。

公众号仅接受安全模式，加密接收方、签名/时间窗、严格XML/大小限制、消息ID摘要防重放；普通文本留聊天，人工回复同事务outbox。发出后结果不明标uncertain，进程中断sending超2分钟同样待核实，不盲目重发。密钥/Token/OpenID不记日志。

图片5MiB、格式/魔数、sharp真实解码、2000万像素、单帧/两并发/超时、最长边4096、去元数据；bytes与file_metadata同事务。旧图授权读取懒清洗。精确照片只准本人/有业务关联专岗/管理层；公开封面必须总部独立上传并已发布，草稿不公开，私有现场照不能转换为公开素材。尚未部署病毒扫描、对象存储生命周期与异地内容审查。

审计包含requestId/主体/岗位/动作/对象/时间，导出另记录范围/方法版本；摘要链检测篡改，不等于外部不可篡改存储。已有本地备份/恢复/安全边界测试，正式HTTPS、负载/渗透、密钥轮换、监控告警、异地恢复及真实平台联调仍待验收。当前官方npm审计0漏洞是时点结果，不保证未来依赖无风险。
