# 页面结构与角色入口

访客在首页进入 `pages/join/index`，提交加盟资料和付款截图。总部在 Web 核实到账并审核，申请人从消息查看结果，按退回意见补件或使用获批后的个人激活码。

访客自定义底栏显示首页、网点、我的。加盟商显示工作台、网点、月报、我的。客服由「联系总部」入口打开。「我的事项」承接待办和通知。旧路径仍用于兼容历史消息。

| 主包路由尾段（17 页） | 用途 |
| --- | --- |
| `home` | 公众首页、加盟商工作台、当前待办和经营摘要 |
| `login` | 登录与首次激活 |
| `join` | 加盟资料、付款凭证、申请查询及补件 |
| `outlets`、`outlet` | 公开目录、我的网点、网点详情及地址。加盟商地图失败时可重试或返回同一网点列表，保留搜索和已授权地址。 |
| `reports`、`report` | 月报列表、填写、草稿、历史与更正。已审核月报的更正错误在提交按钮旁显示，修改更正原因后清除提示。 |
| `fees`、`finance` | 账单与缴费、历史及线下凭证、退款、票据 |
| `requests`、`location` | 业务申请原单、位置核验与历史 |
| `support` | 联系总部、普通咨询及正式工单 |
| `tasks`、`messages` | 我的事项、通知兼容入口及原对象跳转 |
| `profile` | 我的账户及相关业务入口 |
| `discover`、`service-detail` | 集团栏目与已发布业务详情 |
| **分包路由尾段（4 页）** | **用途** |
| `dashboard` | 经营看板与授权导出 |
| `agreements` | 服务协议及历史 |
| `security` | 账号安全、绑定状态及账号变更 |
| `training` | 既有培训业务与历史的受限入口 |

全部实际路由为 `pages/<尾段>/index`。 [路由注册源码](../miniprogram/app.json)

## 总部 Web

[总部入口](../admin-web/index.html)加载管理工作区。管理层分派和治理，运营、财务、位置及客服人员按岗位查看队列，从列表进入原单办理。权限与导出范围见[岗位明细](handoff/02-三方关系与权限明细.md)。

V4.1 的 20 页交互历史见[逐页开发对照](handoff/08-小程序逐页交互与文案.md)。当前加盟申请链路见[小程序人工验证](../miniprogram/README.md#运行与人工验证)。
