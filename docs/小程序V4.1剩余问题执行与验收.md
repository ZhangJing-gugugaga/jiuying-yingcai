# 九盈英才 V4.1 剩余问题执行与验收

以 V4 提交 `17f1a420d4f3d608230157b33bf8c886cc210d4b` 为基线。按用户提出的剩余问题处理。原 V4 源码包独立保留。

| 工作包 | 文件 | 验收条件 |
| --- | --- | --- |
| 工单恢复 | `pages/support`、共用存储与命令接口 | 同一会话可选择恢复最近的工单草稿。重新核对所属网点与关联工单。网络未确认时，同一提交重试继续使用原请求键。 |
| 位置恢复 | `pages/location`、共用存储 | 同一会话、网点、月份和总部状态恢复地址与说明。恢复后重新确认位置和上传现场照片。更换账号、状态变化及成功提交覆盖。 |
| 加载及屏幕适配 | `styles`、高频入口与自定义底栏 | 首次加载、已载入刷新、空和失败各有明确反馈。小屏和长文不影响主操作。安全区留出底栏。 |
| 分包、诊断、验收 | `app.json`、构建脚本、开发诊断 | 低频页面按需加载，既有路径继续注册。验证主包体积、正式构建及脱敏日志。单列微信实际运行和集团独立试用状态。 |

本轮在隔离账号和数据库里复验。代码成功、编译、微信模拟器及集团用户实操分开计数。网点位置、账单和客服处理沿用当前业务规则。
