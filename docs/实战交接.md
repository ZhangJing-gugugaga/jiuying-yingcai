# 九盈英才 V3.4.3 实战交接

> 历史资料。下文的“当前”“本轮”及验收数字均指报告出具时的版本。查阅 [V4.1 交接说明](handoff/00-开发交接总说明.md)了解现行范围及验收进度。

## 首次接通

1. 保全现有数据库，使用 `node scripts/backup.cjs create <完整备份路径>`，随后执行 `verify`。在复制库执行 `npm run migrate` 并核对资料，正式升级使用编号迁移 023–027。回退服务版本前用同一份复制库验证旧应用读取，保留新增业务证据，数据库恢复只能由管理员根据实际新增写入决定。
2. 首位总管理员通过已有受控部署脚本初始化。后续总部人员由总管理员建个人账号，按人签发一次性激活码。建议把普通用户、一级管理员、总管理员作为入口名称，权限由后台启用的个人账号决定。
3. 网站对外提供经过审核的 HTTPS 域名。总部微信扫码需要微信开放平台已审核的网站应用，配置网站 AppID、Secret 和授权回调域名。短信需要腾讯云短信账号、SDK AppID、签名和获审模板。具体变量见 `.env.example`。正式身份配置保存在服务器。
4. 总部在「人员与交接」设置个人岗位、自动分派和工作电话。电话使用可对指定网点公开的工作号码。审批表单导出另行授权网点、类型和字段。
5. 用总部培训入口登记实际课程，确认后发布。网点负责人录入本店可核验学员并提交资料。区域培训审核按需单独授权。

## 日常验证

- 加盟商提交月报或申请后，从原单查看待办、审批和公开联系信息。总部经办人在个人队列处理，总管理员可以查阅和安排交接。
- 推广前用两家不同加盟主体、两位同岗位管理员及总管理员走一遍实际处理，重点检查跨网点访问、已改派、导出审计和撤回后的权限。
- 验收证据需记录当前源包的 SHA256、实际使用端、请求编号、处理前后状态、相关对象和操作者角色。正式平台回调、短信送达、真机位置及拨号保留各自结果。
