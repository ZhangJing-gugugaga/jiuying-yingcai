## D04 历史月报重结算

| 环节 | 实际行为 |
| --- | --- |
| 更正或撤销 | 收入更正经过财务复核后生效。更正生效或撤销复核通过时，旧快照失效并生成该快照对应的总部管理待办。收入更正处于初审、财务待办或退回时，原有效版和正式数据继续保留。 |
| 责任和影响 | 待办默认归总部管理层，可分派给在职管理人员。待办按原快照唯一标识约束，相同请求重放只返回同一业务结果。同次重结算的不同网点事件累计到原待办，记录网点、版本、时间、操作主体和请求编号。 |
| 确认及关闭 | 管理层通过待办确认。已指定个人时由当前责任人办理或先完成转派。事务同时创建新快照、链接旧快照，并记录待办关闭时间、处理人和新结算编号。 |
| 快照保留 | 新快照保存月报版本、已批准汇总调整编号、方法版本和计算时的指标值。旧快照继续可查。旧库可按已保存的版本关系和审批情况恢复影响，无法定位的旧变更标记为待核对。 |
| 正式统计和导出 | 失效后当期正式统计缺失。确认后看板、同比环比的期间数据、总部排名、CSV 和经营导出使用新快照。若撤销了唯一的有效月报，新快照是空范围，指标保持缺失，受影响加盟商可查本人范围的结算结果。 |

按现有有效版本和既有汇总调整计算整数分金额。跨月退款归属、税费归期、历史财务认定等待集团签认。未给旧快照补写缺乏历史证据的数值。

## D08 报送期限与逾期

- 报送资格、月报上下文、补报和免报核验提醒、总部业务队列、加盟商首页、覆盖统计以及经营导出由服务端解析。
- 无已发布制度时沿用既有次月 5 日自然日兼容口径。已发布制度中截止日留空时，截止未配置，逾期未知。配置有效时稳定采用其自然日，进入次日后才显示逾期。已提交月报保留提交时的日期、逾期和制度编号。
- 符合报送资格的历史月仍可补报。覆盖项目分别显示逾期未报、逾期补报、逾期未核验免报。截止具体时刻和节假日顺延待集团签认。
