# 组件开发规范

小程序页面按同名 JS、JSON、WXML、WXSS 组织。公共视觉变量、布局及控件样式从 [app.wxss](../miniprogram/app.wxss) 统一引入。角色底栏集中在 [custom-tab-bar](../miniprogram/custom-tab-bar/)，修改跳转时同步检查登录恢复和历史消息深链。

总部 Web 使用 [admin-web](../web/) 的原生模块与样式。涉及 API 请求时复用客户端封装，业务可见性由服务端复核。依赖通过根目录 package.json 和锁文件管理。跨页面共享状态优先复用现有 utils 或业务模块。

表单提供可见标签与字段级错误，状态同时使用文字和颜色。Web 操作支持键盘聚焦，按钮使用明确动作名称。提交期间显示进度，结果未知时保留原单和重试上下文。复测窄屏、长文本、空列表、错误与重试状态。

## 原型组件拆解

下表中的“建议”是下一轮工作。源文件指向当前逻辑归属；同一页面独有的块优先写成页面模板。通用间距、字体和状态色见[设计规范](../DESIGN.md)。

| 组件 / 原型位置 | 输入与可见状态 | 事件、目的地与复用方式 |
| --- | --- | --- |
| 品牌头图、问候区（图 1、2 顶部） | 公众用已发布品牌标题，加盟商用当前负责人名称或角色回退。城市图右对齐，左侧标题始终清晰 | 在 [home](../miniprogram/pages/home/index.wxml) 内做两个变体；图片属于装饰层，标题与入口可独立阅读 |
| 标题栏、业务磁贴（图 1 五大业务） | 标题、辅助动作、已发布的 service-1 至 service-5、封面与标题。加载、空、部分发布、图像失败各有呈现 | 复用 t-grid、t-icon、t-empty；磁贴按服务 ID 进 service-detail，“了解更多业务”进 discover 的 services 栏目 |
| 网点引导、集团介绍、联系我们、登录条（图 1 中下部） | 两个地域入口，简介正文与可选照片；电话、地址、官方微信按可用数据单独显示 | 公开网点进 outlets；栏目与合作进 discover；热线复用拨号、客服进 support；登录进 login、申请进 join。展示地图和可交互地图分开 |
| 网点范围条（图 2、3） | 授权总数、已选 ID/名称、可选营业状态。0 店显示首店申请进度，1 店显示店名，多店默认显示全部授权网点，同范围查询就绪后提供单店选项 | 建议用原生 picker 或选择面板；支持分页，按 ID 选择，取消保持原值。切换触发所属数据重读；首店继续复用 [home 处理逻辑](../miniprogram/pages/home/index.js) |
| 常用业务格（图 2） | 动作名、图标、短说明与办理资格。六格是上限；无培训记录时收起相应入口 | 复用网格布局和现有导航工具。月报进 reports，费用进 fees，客服进 support，我的网点进私有目录，培训依已有原单，“更多”展示已有业务目的地 |
| 待办行、历史行（图 2、3） | 对象 ID、网点、业务月、类型、面向申请人的原因、状态、可办动作。无原因时隐藏原因文字；未读提示与业务状态分别显示 | 优先复用[我的事项](../miniprogram/pages/tasks/matters.js)的目标解析及重新校验。建议预览最多 4 条待办、3 条记录；总数由同一范围的服务端返回。历史行点开原单，行内动作避免冒泡触发两次 |
| 搜索筛选、网点卡、地图回退（图 3、4） | 公开视图用已发布名称、地址、状态、公开坐标；私有视图加授权经营摘要。无照片可隐藏图槽；无费用数据展示缺省态 | 沿用 [outlets](../miniprogram/pages/outlets/index.js) 的公开/私有行模型和分页；搜索支持键盘确认与按钮。地图错误保留地址和当前范围，可重试或回列表 |
| 状态标签、退回反馈、对象摘要（图 2–4） | 状态、业务类型、对外可见原因、网点、月份。用文字区分已提交、已通过、财务复核、退回；金额与账期并列 | 复用 [format](../miniprogram/utils/format.js) 的标签与色调。状态标签只表达状态，退回卡可指向待修字段，原单详情保留完整原因 |
| 月报字段组、底部动作（图 3、4） | 上下文、单位、已有草稿、可编辑字段、错误、只读版本、提交中。保留营业收入、订单、客流、招生、说明五字段 | 复用 [report](../miniprogram/pages/report/index.wxml) 的输入、保存、确认提交、更正及版本操作，错误贴近控件；“已通过”版本的更正入口和原因独立 |

[月报数字字段样板](../miniprogram/components/number-field/index.wxml) 接收字段名、标签、初值、键盘类型、禁用态、提示和错误。组件使用原生数字输入框，向页面传递 `fieldinput` 和 `fieldblur`。页面继续负责校验、草稿和提交，保留字段外层的滚动定位锚点。
| 激活字段组（图 3） | 一次性激活码、密码、确认密码、显隐、服务端错误、提交中、成功；视觉上区分操作和规则说明 | 在 [login](../miniprogram/pages/login/index.wxml) 的激活模式复用 t-input/t-button、原提交及跳转。普通登录保留原鉴权分支 |
| 角色底栏、空态与加载态（全图） | 角色、当前 tab、有无数据、读取错误。角标有来源才显示；装饰图标免重复朗读 | 复用[底栏](../miniprogram/custom-tab-bar/index.js)、t-badge 和公共骨架。首载、刷新、局部失败分别处理，重试只针对失败数据，tab 切换保留原参数交接 |
