## 人工验收

1. 在隔离环境启动后端及总部网页；用加盟商测试账号打开原生工作台、服务费和月报。选择两种模拟支付，核对成功、失败、取消、重复通知及退款，核对总部实收和 CSV。
2. 以管理层和财务分别确认历史月报更正以及重结，检查影响网点、旧结算、新结算、加盟商消息、看板与导出。
3. 在总部发布五个公司审核过的栏目，重新进入访客服务页和单项详情。验证草稿隔离、撤回、恢复及图片权限。
4. 以客服和管理层走升级及补充说明。验证仅显式用户回复入站内/公众号出站队列。用本人、异主体、财务和运营分别查申请和历史。
5. 测试和验包证据见完整测试报告。现场设备与支付商户的真实条件见下节，实际平台凭证由集团配置。

## 上线资料和后续工作

- 集团确认正式合同收款、开票主体、渠道商户与应用映射、实际支付宝产品、微信及支付宝商户权限、回调域名、密钥运维与清算对账人。
- 确认自然月账单可自动补期界限、部分月和启停规则、历史原账的抵扣及冲正策略、月报截止时刻和节假日规则。
- 提供五项业务正式名称、正文及有发布权的图片，正式公众号配置、真实发送授权及渠道验收账号。
- 提供正式 AppID、合法域名、HTTPS、隐私指引及真机验证环境，确认测试角色和签收人。执行平台联调、实际设备、生产部署回退和甲方验收。当前交付和验证状态以完整测试报告为准。
