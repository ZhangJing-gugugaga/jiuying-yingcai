# 服务费现行规则与明确排除事项

## 保留的现行咨询服务费规则

1. 每个网点按自然月独立形成咨询服务费账单。
2. 账单（应收）与支付订单/付款尝试分开管理。
3. 即使加盟商没有点击支付，总部也应看到有效应收账单。
4. 加盟商负责人可以查看自己名下各网点账单。
5. 原型历史展示三档暂定月价：1980元、4800元、9800元；价格、套餐服务内容、套餐决定权、变更权、账单生成日、缴费截止日仍待集团确认。
6. 暂停营业不会自动暂停收费。
7. 加盟商必须单独申请暂停收费，总部批准后才可调整。
8. 已支付但尚未享受服务原则上优先顺延，特殊退款另行审批。
9. 暂停期间折算、调整归属月份、服务是否同步暂停、协议到期后能否顺延等仍待集团业务及财务共同确认。
10. 原账单、付款记录、审批记录不可覆盖。算法未定时，原型只展示“待核算的服务费调整”，不自动计算金额、抵扣月份或新到期日。
11. 真实微信支付未接入，原型只模拟。

## 用户明确要求不展开的事项

用户在本轮明确表示，之前手写记录中提到的以下商业模式内容“这些不写了”：
- 前期一次性项目费用；
- 后期按月运营抽佣/分流；
- 围绕公司账户/合同账户的新增商业结算模式及相关商业模式推演。

以上内容不写入当前需求基线、不扩展为产品模块、不在夜间执行中自行加入。

注意：这不代表删除已有的“每网点自然月咨询服务费”需求。原有服务费账单、模拟支付、暂停收费申请仍是既有产品功能，继续保留。
