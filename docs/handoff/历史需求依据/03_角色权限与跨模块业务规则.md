# 角色权限与跨模块业务规则

## 角色

### 加盟商负责人
- 一个加盟商一个负责人账号，由总部创建。
- 管理自己名下多个网点。
- 只能查看和操作自己所属网点。
- 查看当前有效月报及历史处理摘要，不查看总部内部完整审批详情。
- 可查看和导出本人名下全部网点经营数据。
- 通过小程序在线客服和电话客服联系总部。

### 总部
- 负责加盟商主体、负责人账号、网点档案、月报审核、服务费、位置核验、客服和经营统计。
- 普通经营月报由指定运营管理人员审核。
- 涉及营业收入的历史更正增加财务复核。
- 总部高级管理员发起错误审批的纠正/撤销。
- 专门的位置核验人员负责最终位置核验。
- 总部管理层查看经营排名并导出集团经营数据。
- 客服统一接收工单；客服默认不查看加盟商经营/财务数据，必要时由总部授权。

### 区域运营
- 默认只读。
- 仅在总部明确授权后查看指定指标、指定网点。
- 仅在额外授权后审核指定网点的经营月报。
- 不因月报审核授权而获得暂停收费、退款、账号、财务调整或其他审批权限。
- 位置核验数据不自动对区域运营开放。

### 消费者/公众
- 查看普通网点公开信息：名称、对外地址、普通地图标记、营业状态。
- 通过微信公众号和小程序联系总部客服。
- 不得查看内部经营、财务、账单、支付、审批、精确GPS和内部核验记录。

## 跨模块不变量

1. 网点是经营报表与咨询服务费的基本单位。
2. 一个加盟商主体可绑定多个网点；负责人账号属于加盟商主体。
3. 同一网点、同一自然月一份当前有效正式汇总，可以存在多个历史版本。
4. 当前营业状态不能代替历史月份的实际状态。
5. 网点暂停营业不等于暂停收费。
6. 月中暂停仍报当月实际数据；整月暂停经总部确认可免报，免报不等于零值报表。
7. 账单应收、支付订单、实收流水、退款、服务期限、费用调整必须区分。
8. 未审核报表不进入正式经营统计。
9. 消息已读不等于业务完成；客服答复不等于审批完成。
10. 位置变更必须单独申请并经总部审批。
11. GPS定位核验为主动操作，不是后台持续追踪。
12. 客服工单负责人保持总部客服；内部协助不改变工单负责人。
13. 消费者投诉通知加盟商时，限制披露个人信息。
14. 任何统计汇总调整不能覆盖原始月报。
15. 正式业务记录必须可追溯：对象、操作者、时间、原因、前后值、审批与生效状态。

## 重要跨模块流程

### 月报通过
加盟商提交版本 → 总部待办增加 → 总部通过 → 当前有效版本更新 → 正式经营统计更新 → 加盟商可见状态更新 → 消息通知。

### 月报退回
总部退回并写明原因 → 加盟商查看退回原因 → 修改并形成新版本 → 再次提交 → 总部复核。旧版本保留。

### 历史月报更正
加盟商发起 → 总部审核 → 若涉及营业收入增加财务复核 → 新版本通过后成为有效版 → 统计更新，原版本留存。

### 总部统计汇总调整
总部调整汇总层 → 记录调整对象、期间、前后数值、原因、操作人和时间 → 不修改加盟商原始月报。涉及营业收入时不得绕过财务复核。

### 新增网点
加盟商填写资料和地图位置 → 提交总部 → 总部审批及位置核验 → 通过后创建唯一网点档案、绑定加盟商、初始“筹备中” → 实际开业由总部确认“营业中”。

### 地图月度核验
系统每月提醒 → 加盟商主动获取GPS并提交地址、现场照片 → 系统按待确认的允许误差范围识别位置变化 → 总部专门位置核验人员审核 → 通过或异常；逾期标记异常，由总部人工处理。发现不一致先要求解释和证明，位置变更另走申请审批。

### 服务费
协议/价格版本确定 → 按网点自然月形成应收账单（无需等用户点击支付）→ 加盟商发起模拟付款 → 真实环境需服务端核验渠道结果 → 更新实收。暂停收费必须独立申请，总部批准；算法未定只显示待核算调整。

### 全渠道客服
用户进入对应渠道 → FAQ自动回复 → 用户选择是否转人工 → 普通咨询留聊天记录；投诉/售后/业务异常建工单 → 统一队列由客服自助接单 → 总部客服持续负责，必要时协作调查 → 标记完成关闭 → 用户可查看历史；未解决时新建关联工单。

## 数据隐私

- 公共网点数据与内部经营/财务数据隔离。
- 精确GPS和内部位置核验记录仅加盟商和总部可见。
- 客服人员默认不访问加盟商经营和财务数据。
- 消费者投诉通知加盟商时，只共享处理所需内容，避免暴露不必要的个人信息。
- 前端隐藏按钮不是安全控制；正式系统需后端逐次验证主体、网点归属、角色和授权范围。
