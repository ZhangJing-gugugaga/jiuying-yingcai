# 九盈英才（和悦集团V2）项目总说明与当前阶段

## 1. 项目目标

建设一套服务集团总部与加盟商的统一业务平台。当前工作重点是**可供甲方体验和确认需求的独立HTML小程序测试原型**，以加盟商负责人日常使用为主线，总部作为审核、管理和客服协作方。消费者端保留必要的公开网点信息与客服入口，但不作为当前原型主展示重点。

未来产品形态包括微信小程序、iOS/Android APP和总部电脑管理后台。当前HTML只用于业务流程与页面体验确认，不能宣称真实后端、正式登录、支付、GPS核验、在线客服或多端系统已经开发上线。

## 2. 当前产品名称

**九盈英才**。后续原型标题、登录页、工作台、演示文案和甲方材料统一使用该名称。项目交接历史名称“和悦集团V2”作为项目版本/来源标识保留。

## 3. 当前阶段

- 当前阶段：甲方业务需求确认、规则梳理、交互原型体验。
- 本阶段交付：可独立打开的HTML测试原型、可操作的模拟业务流程、需求状态记录和测试报告。
- 当前不做：正式生产小程序、APP上架、真实支付接入、生产服务器部署、真实用户认证和正式数据库建设。
- 可以在原型中模拟：加盟商/总部身份切换、审批、支付结果、客服工单、定位核验、消息通知、数据看板。
- 必须明确标识：模拟数据、模拟支付、模拟定位/地图、模拟客服、规则待定。

## 4. 产品主线

1. 加盟商与负责人账号。
2. 网点档案、生命周期与地图位置核验。
3. 月度经营报送、审核、更正与经营统计。
4. 每网点自然月咨询服务费账单与支付。
5. 业务申请、审批、消息和待办。
6. 全渠道客服。
7. 加盟商经营数据看板与总部经营汇总。
8. 角色权限、数据隐私和操作留痕。

## 5. 当前展示原则

- 默认进入加盟商负责人工作台。
- 主要展示加盟商日常操作：管理网点、填月报、查看账单、申请业务、联系客服、查看经营数据。
- 关键流程可以切换总部角色，完成审核/处理后再回到加盟商查看结果。
- 公众不作为主导航的核心讲解对象，但普通网点公开信息仍保留；消费者通过微信公众号和小程序进入客服。
- 不把42/111/123等内部需求数量当作首页卖点。
- 每个业务场景用具体对象说明：谁使用、做什么、交给谁、处理结果是什么。
- 页面展示要让甲方容易判断实际工作是否符合集团日常管理。

## 6. 重要事实与来源边界

此前交接包包括42项一级功能、111项原始细则、12项增补、123项编号追溯、8条业务演示场景和历史原型。原交接包中的Excel是历史审批模板，不等于已完成甲方签署。原型“可操作”标签不等于生产可用或完整验收。

新需求基线中明确的用户选择来自2026-11-17至2026-11-18当前对话；若与旧原型或旧需求文档冲突，以当前用户最新明确选择为准。
