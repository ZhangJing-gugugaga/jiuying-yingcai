# 三方关系与权限明细

## 1. 三方如何协同

| 管理关系 | 上游负责什么 | 下游负责什么 | 可见内容与交界 |
| --- | --- | --- | --- |
| 总管理员 ↔ 一级管理员 | 建个人账号、定岗位、授予及撤销权限、设分派规则、改派、交接、审核关键业务和检查审计 | 激活后以个人账号接单，在授权岗位和责任范围办理，写清结果或补件依据 | 总管理员能够查看管理视图和留痕。受派人看到与其岗位、网点及当前职责匹配的数据 |
| 总管理员 ↔ 加盟商负责人 | 建主体和负责人、分配或确认网点归属、签发激活、冻结换绑、发布制度与集团内容、管理公开联系方式、处理需要管理层批准的请求 | 对本主体提交资料，及时补件或更正，查看审核状态和业务结果 | 主体关系用于判断网点、历史、账单、导出和资料访问。加盟商看获准公开给申请人的说明 |
| 一级管理员 ↔ 加盟商负责人 | 按职责审核、核验、退回、复核、处理咨询及派生事项 | 在原单查看、补件、重提，缴费或提交凭证 | 关联原记录 ID 和当前责任。站内消息提示，业务待办和审核按原对象处理 |
| 加盟商主体 ↔ 网点 | 一个加盟商主体一个有效负责人账号 | 同一主体可有多个网点，每个网点保有自己的月报、账单、核验、合同及状态历史 | 办理时核对网点、月份和记录。换负责人后保留原主体业务历史 |

这里的「一级管理员」涵盖总部经办岗位。11 月 25 日沟通的「一级代理」「二级代理」属于加盟主体级别，分级授权在[下一轮开发计划](../../TODO.md#下一轮分级代理报送)跟踪。总部后台负责审批和治理，加盟商小程序负责公开浏览和加盟业务。区域运营作为总部授权的受限岗位。访客是单独的公开访问身份。

## 2. 总管理员功能清单

| 职责 | 功能点与管理细节 | 审计或约束 |
| --- | --- | --- |
| 首次开通 | 由受控部署初始化首位账号；可创建其他总部个人账号和加盟商主体，签发绑定身份的一次性激活 | 账号与自然人对应。员工激活与已有个人登录分开 |
| 员工与权限 | 指定运营、财务、位置、客服、区域运营或管理岗位；为区域设网点、指标、额外月报审核权限及有效期 | 变更有依据、绑定版本与操作人。停用或换岗前核对未完待办。禁止自行停用或变更本人岗位 |
| 加盟商与档案 | 开主体账号，维护状态，核实负责人/手机号变更。管理网点状态、关系维护及批量导入 | 旧认证撤销。批量导入先校验预览。已关闭网点留历史 |
| 分派与交接 | 配置网点＋任务类型＋接收岗位的个人分派；手动改派；在未完成事项存在时交接给另一名已激活且具备对应岗位范围的人员 | 留原因、对象、原经办、新经办和请求号。变更后应检查旧分派规则及回落岗位队列 |
| 业务审核 | 可处理适用的运营审批和管理审批，查看审批时间轴，发起月报误审批撤销、统计调整、费用调整与错账纠正 | 财务复核、位置最终核验等专岗动作按自身规则办理。不以总管理员身份替代独立财务复核 |
| 经营与财务治理 | 全集团看板、分指标排名、正式结算和重结算、授权导出，维护价格与合同配置、核对总账及异常 | 正式结算有覆盖范围及快照。金额来源可追踪。标准业务动作不得覆盖原报表或原实收 |
| 内容与服务治理 | 发布集团业务、案例/资讯、公开地址和联系方式；管理 FAQ、客服时间、严重投诉；维护已获准公开的工作号码 | 草稿和未授权信息留在总部。公开状态可撤回，严重投诉有管理处置记录 |
| 审批导出治理 | 指定受支持的岗位、网点、类别、字段和有效期。可撤销。查看授权、下载和操作审计 | 导出的资格与普通审批资格分别校验。内部备注、身份、图片和精确坐标由服务端固定字段控制 |
| 运行与事故管理 | 管理周期任务与运行健康视图，查询审计、队列、备份发布及恢复情况 | 平台运维密钥由受控部署负责。测试环境与集团生产环境分开 |

## 3. 一级管理员按岗位办理

| 岗位 | 可处理 | 可见及导出边界 |
| --- | --- | --- |
| 总部运营 `ops` | 普通月报初审/退回，新增、营业状态和位置变更等运营审批，核对免报和费用提案，按授权处理汇总层调整相关事项 | 为办理业务可看必要网点、月报、申请和本岗位意见。应收与调整资料按接口投影。运营收款流水和实收不是默认工作区权限。审批导出单独授予 |
| 财务 `finance` | 历史月报收入复核、撤销复核、停费和费用核算的相应复核、线下款、错账补账及独立复核、退款与发票处理 | 可看必要账单、支付、实收、退款及财务审核资料。专岗核验资料与公众内容管理独立。审批导出需授权并限所在业务范围 |
| 位置专岗 `location` | 复核月度现场定位和地址，处理新增/变更地址资料核验，处理异常补充并确认基准 | 仅在授权业务中读取核验图片、定位和核验意见。按岗位可导出位置或申请审批允许的非隐私字段 |
| 总部客服 `support` | 对待接单和本人负责的咨询/工单接单、回复、补件、协作、升级、关闭及跟进 | 私下协作留在内部。默认不能查经营、实收或私人定位；加盟商获得处理所需脱敏信息。总管理员对严重升级负责 |
| 区域运营 `regional` | 指定网点和指定指标的运营查看。有额外审核授权时可审核指定网点的普通经营月报 | 指定网点、指标、操作权和有效时间分别生效。月报审核授权无权扩大到其他网点、停费、退款、身份管理或定位；报表审批导出还需独立授权 |

已经分配给个人的受支持任务应由当前经办办理。同一岗位的其他人进入原单也要经过服务端责任校验。缺少有效分派人时按既有岗位队列接收。历史资料维持原操作人的留痕。

## 5. 管理动作的实际规则

### 人员开通、分派、交接

- 总管理员创建员工个人标识和岗位。一次激活成功后才可成为受派人。账号登录通过服务端确认 `subject` 与岗位。
- 自动分派按「网点 × 任务类型 × 岗位」命中一个启用规则。适用项包括月报初审/财务复核、运营/财务申请、地址核验、月度核验及异常、客服、统计调整和费用核算。岗位变化、停用、未激活或缺少有效规则时回岗位队列。尚无网点的申请使用适用总部队列。
- 更换经办时，关联对象和已提交资料继续使用原记录。改派认领按状态和岗位核对。批量离职交接转移未完事项并停用旧账号，因权限失效的旧会话须重新认证。更改分派规则与转移存量是两项操作，交接时一起检查。

### 工作电话

按已有可见原单找当前经办的已发布工作号。无匹配时依次尝试网点默认工作号、指派客服的已发布工作号和总部公开客服号。仅在已有网点和记录授权下返回工作号码及来源。管理端入口由总管理员设置与撤下。个人登录手机号保存在身份模块。 [工作电话实现](../../server/work-contacts.cjs)

### 审批表单与经营导出

审批表单 CSV 读取本人岗位、授权类别、网点、字段和有效期的交集。运营、财务、区域可按允许范围导出月报，运营、财务、位置专岗可按规则导出相应申请，位置专岗可导出核验允许字段。区域月报字段再受其指标及网点范围限制。单次审批 CSV 上限 1000 条，记录授权修改、下载人、范围、行数和请求编号。经营看板导出和财务台账导出各有其授权和范围，分别走各自接口。 [审批导出实现](../../server/approval-export.cjs)

### 三方争议和审计

- 状态变化由已授权的实际审批、写入和确认产生。并发审批时只有第一个符合条件的提交生效，另一人刷新后核实结果。
- 发起、审批、财务复核、渠道确认、知识库回复和通知是可独立追踪的动作。财务复核及其他要求独立操作人的动作必须使用实际不同的个人主体。
- 帐号切换、区域授权撤销、网点无权查看、附件未授权时，列表、详情、深链和导出按当时权限执行。错误处理保留请求号供查证。
- 审计查阅按岗位脱敏。提交者可看业务结果、可公开的处理说明和必要的历史，客服协作备注和员工个人身份资料由有权岗位查看。
