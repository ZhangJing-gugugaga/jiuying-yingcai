## 2. 下一步开发和验收建议

分级代理报送已完成本地实现，[独立签收](../../TODO.md#本轮分级代理报送本地已实现)仍需独立复验；同步准备标识接入。以下工作包继续跟踪现版独立试用、真机和目标环境验证。

优先级按对试用或上线的影响提出，排期由项目同事确认。先走真实办理路径再修可复现问题，避免业务现场靠演示账号或直接改库绕过角色流程。

### 工作包一 · 微信实际交互和集团独立试用

- [ ] 针对固定候选包，核对源码 SHA、测试 AppID、IDE 实际路径和隔离 API。若导入提示项目作者信任，确认授权后打开模拟器并捕获第一条实际业务请求。
- [ ] 按当前 22 个路由和 [角色验收场景](05-验收与开发协作.md) 逐页执行，记录截图、页面路径、请求号及账号角色。重点复验系统返回、键盘、窄屏、客服草稿、定位草稿、分包首次加载和失败提示。
- [ ] 由未参与开发的集团人员按工单角色体验并记录问题。每个确认问题用可打印的最短步骤复现、定位、回归。建议由产品负责人和测试负责人核对记录后推进试用准入。

### 工作包二 · 总部实班、对账与授权运维

- [ ] 用两名相同岗位经办、两名不同主体加盟商以及财务、定位和管理层测试账号，完整执行分派、改派、撤权、离任交接和授权导出。检查存量责任与未来自动分派是否一致。
- [ ] 运营和财务共同核对同网点错账、补账、暂停收费及退款的原始凭证、金额分值、替代账单、审计和前端状态。用实际批准的制度确认允许范围。
- [ ] 若发现权限或台账差异，从 `server/repository.cjs`、`shared/operations.cjs`、`server/finance.cjs` 检查列表、详情、导出或写入的相同范围。新增对应回归，复核独立自然人操作及重复请求。

### 工作包三 · 真机与渠道联调

- [ ] 集团收齐机构资质、测试 AppID、HTTPS 合法域名、隐私指引和授权测试设备。先复测登录、GPS、图片、地图和文件打开。
- [ ] 对获批启用的微信登录、总部扫码、短信、公众号、微信/支付宝支付及退款分别确认凭证和可用产品。对账测试采用明确的沙箱、测试或经授权渠道。真实资金动作需集团授权。
- [ ] 对定位、支付和外部消息记录渠道来源和结果，保留提交未到达、结果不确定或重复回调证据。订阅消息、地址编码、对象存储、病毒扫描按实际纳入范围评估工作量及成本。

### 工作包四 · 制度裁决、部署和发布回退

- [ ] 由业务及财务负责人把第 3 节规则签成可版本化的政策，带生效日期、例外场景和审批人。设定默认值前补验收样例。
- [ ] 运维在脱敏目标库副本执行备份、重复迁移、完整性和账务核对、角色演练及应用回退。记录停写窗口和恢复用时。
- [ ] 在目标环境验证 HTTPS、数据库容量及并发、备份恢复、告警、可观测性和回滚。由集团收齐真机、平台和安全证据后安排正式提审和上线批准。

| 主题 | 需要明确的输入 | 责任方建议 |

| 月报和统计 | 提交、审核、逾期具体时刻、节假日，收入含税与退款归期、有效订单冲减、招生适用性生效、部分覆盖结算、独立撤销复核 | 集团运营、财务 |
| 协议与财务 | 服务、收款及开票主体；正式价格/套餐、出账和付款截止；首月、筹备期、部分月、套餐变更、预付、退款、抵扣及服务期顺延 | 集团财务、法务 |
| 网点与账号 | 转让/重开后的历史欠费责任及访问；换绑、手机号变更所需证明；岗位名单、区域范围与授权有效期限 | 运营、业务治理 |
| 位置与隐私 | GPS 精度、距离阈值、有效坐标系、照片策略、期限与补件、逾期和豁免 | 位置岗位、集团合规 |
| 客服和公开内容 | 工单分级，工作时段、SLA、电话、消费者脱敏；五大业务素材、公开网点地址坐标、联系人和隐私文案 | 客服、内容、合规 |
