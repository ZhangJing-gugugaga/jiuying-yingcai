## 校验方式

在 Windows PowerShell 中对收到的交接包运行以下命令，核对 SHA256 Markdown。

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\九盈英才_V4.1_开发交接包.zip'
```

解压到空目录，打开 [00 开发交接总说明](00-开发交接总说明.md)。如需核对源码文件，可在同一根目录按包内路径对照清单。原始 V4.1 档案保留随初次交付返回的验收数据，应用版本的发布判断应同时核对实际微信交互和集团试用状态。
