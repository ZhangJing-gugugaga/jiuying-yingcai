# 验收与开发协作

## 1. 分工

| 团队职责 | 交付 |
| --- | --- |
| 产品和运营 | 维护范围、流程及规则，确认岗位、网点和材料，不明规则给出决议和生效期 |
| 小程序同事 | 负责页面、导航、表单、交互和端侧恢复，提交实操截图与请求号 |
| 总部 Web 同事 | 负责管理工作区、审批、导出、客服与审计呈现，复核各角色可见导航与办理范围 |
| 后端与数据同事 | 负责权限、状态机、幂等、数据模型、迁移、财务口径及对账，确认写入与历史一致 |
| 测试、运维与发布 | 维护隔离测试账号、版本和证据，安排实际设备及独立试用，验证部署和回退 |

分任务时按业务链路交给一名主负责人。每个改动单写清需求编号、影响角色、入口、API 和数据、旧数据影响、错误处理、实际验证与回退。工作基线使用交付所列同一提交。解压目录不含 Git 历史，协作时使用原 Git 项目对应提交或将该源码快照作为团队仓库的导入基线。

## 2. 隔离验收样本

准备两家加盟主体，其中一家至少三个网点。准备一名总管理员、两名同岗位运营、一名财务、一名位置专岗、一名客服和一名区域运营。配置一条只覆盖指定网点及字段的区域授权。准备普通访客账号、本期已发布公开资料、有效和暂停网点、账单、逾期及草稿样例。所有编号来自隔离库，样本金额和试用配置单独标识。

| 编号 | 步骤 | 核对结果 |
| --- | --- | --- |
| T01 公众与发布 | 游客看集团与五大业务、国内外网点，关闭地图或网络后查地址。管理层更新、撤回一个公开内容 | 公开地址仍可达，撤回内容及附件关闭；访客读不到私有经营数据 |
| T02 登录和换绑 | 总管理员建加盟商、签激活。负责人登录并显示三个网点。批准一次测试换绑，旧账号和会话再访问 | 旧认证失效，新负责人激活后仍承接同主体历史；另一加盟商打不开链接 |
| T03 月报普通审核 | 加盟商选网点与月，存部分草稿，补齐提交。运营先退回再通过新版本 | 原单、草稿、退回理由、版本及运营待办一致。缺项、跨网点和重复在审应被拒绝 |
| T04 历史收入更正及统计 | 由 V1 当前有效出发，提交 V2 收入更正，运营初审、财务复核、管理层重结算 | 在财务完成前 V1 有效；新旧版本和结算快照可追溯；正式看板只用适用结算 |
| T05 分派与交接 | 总管理员配置受派运营，另一同岗位先尝试处理，再改派及停用旧人 | 经办权限随改派更新，旧人不能继续处理，未完成事项、历史与未来规则均核对 |
| T06 区域及导出 | 授权一个网点、部分指标和指定导出字段，尝试导出其他网点/字段；撤销授权再打开 | SQL 查询、列表、详情和 CSV 都服从当前范围。下载审计含请求号、行数 |
| T07 新增与月度位置 | 负责人提交新增资料和现场月度核验；位置专岗判定异常，补件后再核；运营批准新增 | 申请先经位置核验，新增网点只建一次；手工点无法批准月度现场核验；旧位置、新版本及权限正确 |
| T08 费用全链路 | 测试协议出账，Mock 支付并回看原账单。另用隔离线下凭证做复核、退款或账单纠正 | 应收、支付订单、实收、退款各自追溯；重复确认只入账一次；独立复核有效；净额按分核对 |
| T09 停业与停费 | 同一网点分别申请暂停营业和暂停收费，调用授权岗位流程，财务核准提案后抵扣 | 营业状态、收费调整、抵扣月、关联账单及服务期分别变更；未知金额为 null |
| T10 客服与草稿 | 公众咨询，加盟商正式工单填到一半退出恢复，随后提交、客服回复、补件、升级或关闭 | 不误建工单，附件按授权，重复提交仅一单，顾客投诉协查脱敏，历史和评价可回查 |
| T11 事项和原单 | 读消息、从事项进原单，换网点或会话再打开。执行一项真实审批或补件 | 读消息不完成任务；无权原单不可访问；真实业务处理后任务状态正确 |
| T12 培训已有记录 | 用已有课程通知打开原学员，补材料、审阅、核对跨主体 | 历史和权限可用，非授权人员不可读附件 |
| T13 归档和恢复 | 在备份副本重复迁移、验证审计、恢复到新路径，再比对报表和资金记录 | 库完整、版本迁移一致、历史和操作证据可查，回退过程留痕 |

## 3. 记录方式

每次验收至少记录源码提交与 SHA、端别和工具版本、时间、角色和只含测试标识的账号、网点、月份、对象 ID、步骤、预期、实测结果、请求号及截图。验收状态可以是通过、失败、受阻或未执行。请求号用于关联运行日志和关键写入。现场执行人、独立试用人员和上线签收人员分别标明。

| 验收阶段 | 准入材料 |
| --- | --- |
| 接手开发 | 当前包完整、同版本编译和自动化有证据，隔离环境可运行 |
| 集团独立试用 | 当前版本 20 页实际操作、核心链路和权限反向实测，独立人员按岗位完成并登记关键问题 |
| 正式上线 | 集团制度和资料已确定，目标环境 HTTPS、迁移、容量、恢复和回退演练通过，需用的真实平台分别联调，完成微信审核和集团签收 |

当前交接对应开发及隔离环境验收。正式平台、真机和集团独立试用按 [V4.1 原始验收记录](验收证据/V4.1原始综合验收报告.md) 继续。
