# 微信原生小程序

使用 JS、WXML 和 WXSS。主包与分包路由见 [app.json](app.json)，页面与业务入口见[页面结构](../docs/PAGE-STRUCTURE.md)。

TDesign 组件和字体已随源码放在 `vendor/tdesign`，日常调试直接使用。改动组件依赖时，在 `web/` 用 `npm run wechat:vendor -- --check` 核对生成件。

## 运行与人工验证

1. 按[项目 README](../README.md#本地启动)启动后端，在微信开发者工具打开本仓库的 `miniprogram/`。修改后在原项目点「编译」。下面按改动选测。
2. 总部开通账号并签发激活令牌，原生「首次激活」设置12—128位密码，退出后验证密码登录；「我的→账户安全」改密后用旧会话访问应失效。开发身份仅用于本地联调。
3. 网点页输入名称或地区后按键盘确认搜索。超过 50 条时点「加载更多」，检查 200 条之后的数据和无结果筛选，再验证省市区筛选及地图标记跳转。用加盟商打开「我的网点」，模拟地图加载失败，在错误区点「返回网点列表」。确认搜索条件及已授权地址仍在，也可单独验证「重试地图」。
4. 月报填写、提交、退回、重报及结算后核对看板。对已通过的月报发起更正，空原因时确认按钮旁提示，填写原因后确认提示消失，再提交并核对原单与总部状态。查看待处理、退回、通过和已撤销的记录，核对状态文字及颜色。切换账单月份和状态，打开 Excel/PDF 核对授权范围。
5. 总部发布协议价格并生成整月账单；原生登记线下付款→财务独立核验→原生实收记录→申请发票/退款→总部处理→刷新进度。已开票与退款冲突由服务端阻止，不自动冲红或退款。
6. 总部运行周期作业后查看业务待办，打开对应月报/核验/账单；消息已读后原待办仍在，业务完成后才结清。
7. 「集团与服务→合作咨询」填写资料，同意本次联系用途后提交；总部接收/联系/关闭后查看状态和通知，另一访客不能读取旧记录。总部发布内容和FAQ，公众入口查看正式资料、地区网点、公开资料和客服；换另一加盟商账号检查私有报表/账单/申请隔离。
8. 定位仅按钮主动触发；现场照片上传后提交核验；客服在线咨询、正式工单、补充、人工关闭与评价分别验证。
9. 总管理员配置并启用加盟收款信息。访客从首页进入「申请加盟」，提交资料和付款凭证。总部可以退回补件，访客从消息进入原申请并重新提交。总部核实到账并通过后签发激活码。申请人首次激活后登录，再切换另一访客核对申请和凭证访问范围。
