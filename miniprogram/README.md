# 微信小程序

## 本地调试

1. 按[项目启动说明](../README.md#本地启动)启动共用 API。
2. 在微信开发者工具打开本仓库的 `miniprogram/`。目录内含 `project.config.json` 和 `app.json`。
3. 已经打开该项目时，在原窗口点「编译」。默认 API 地址为 `http://127.0.0.1:8787`。

## 源码位置

| 路径 | 用途 |
| --- | --- |
| [app.json](app.json) | 页面、分包和全局配置 |
| [pages/](pages/) | JS、WXML、WXSS 和页面配置 |
| [utils/](utils/) | 请求、会话和导航 |
| [vendor/tdesign/](vendor/tdesign/) | 随源码维护的组件和字体 |

更新 TDesign 组件依赖时，在仓库的 `web/` 用 `npm run wechat:vendor -- --check` 核对当前生成件。

## 运行与人工验证

按改动选测，从实际入口操作：

| 场景 | 重点 |
| --- | --- |
| 申请与首次激活 | 首页申请加盟，经总部退回、补件、核实到账后签发激活码。检查首次激活、密码登录、改密后旧会话及另一访客的访问权限。 |
| 网点与地图 | 搜索、分页、切换地区和返回详情。地图失败时检查「重试地图」和「返回网点列表」，核对原筛选与授权范围。 |
| 月报与催报 | 从待办或催报通知进入同一网点和账期，核对草稿、提交、退回重报及版本。已通过月报的更正需填写原因，核对总部状态。 |
| 账单与凭证 | 从服务费打开原账单，核对线下付款、财务核验、实收、发票或退款申请。检查导出范围。 |
| 待办与通知 | 核对通知落点、原单返回和筛选恢复。消息已读后，原待办仍按业务状态变化。 |
| 咨询、工单与位置核验 | 核对咨询进度、工单补充和处理结果。位置核验从按钮触发，提交前检查现场定位及照片。 |
