# 微信原生小程序

19 个原生页面，使用 JS、WXML 和 WXSS。18 个原始业务页面与 V3.3 新增的业务详情页 `pages/service-detail/index` 共同注册于 `app.json`。深绿、暖白、金色共用设计样式。业务由同一 Node HTTP API、SQLite 和服务端权限及状态机处理。

## 本轮交付

- 原有月报、位置核验、客服与支付链路保留；新增服务协议、线下付款/退款/发票申请、业务待办、集团公开资料/FAQ/合作留言、个人安全五个模块，首页和「我的」已接入口。
- 账号密码登录、总部单次令牌激活、访客登录及改密后撤销旧会话。开发身份入口仅在本地配置与服务端 devLoginEnabled 同时开启时展示，失败时不回退打开。
- 非首页读取 `/api/context`、每集合 `/api/collections/:name` 与按需详情；每次50条，显示总数、加载更多、筛选与空态。辅助网点/账单/实收选择同样能继续加载。首页仅摘要，消息未读总数和持久待办另查有界集合。
- 233条网点与220条账单跨越200条边界测试；名称/地区搜索和省市区筛选；报表月份/状态、账单月份/状态、申请/消息/客服工单/财务申请状态筛选。
- 待办、通知直达月份、网点或记录；已读不完成业务。选择历史客服会话与工单按详情读取。未保存月报输入不因列表加载被覆盖。
- XLSX / PDF 使用 Bearer 下载及 `wx.openDocument({fileType,showMenu:true})` 原生打开，可通过文档菜单处理；不再复制CSV冒充Excel。
- 合作留言校验机构、联系人、电话和需求，必须明确同意仅用于本次联系；本人记录分页、状态筛选与总部跟进通知。不同访客会话严格隔离；退出访客会话后无法从新会话查看旧留言。
- 公开地图只使用明确发布的GCJ-02公开坐标，不泄露内部GPS；未发布坐标显示真实空态。
- 正式brand/services/news/cases/cooperation、FAQ、公开网点资料与总部同源；未发布资料真实显示空态，不创造集团案例。
- 协议展示价格快照、版本、服务/收款/开票主体；线下款须财务核验后计实收，退款/发票仅申请并查询结果，不宣称已执行外部资金或税务操作。

## 运行与人工验证

1. 从根目录按 [项目启动说明](../README.md) 启动隔离开发后端，在开发者工具导入对应包的原生项目。使用获准的测试号。开发构建的回环 API 与本地域名设置适用于模拟器验收。
2. 总部开通账号并签发激活令牌，原生「首次激活」设置12—128位密码，退出后验证密码登录；「我的→账户安全」改密后用旧会话访问应失效。开发身份仅用于本地联调。
3. 网点页输入名称/地区后按键盘确认搜索；超过50条点加载更多，检查200条之后及无结果筛选；省市区筛选与地图标记直达详情。
4. 月报填写→提交→总部退回→修改重报→通过结算→看板核对；切换账单月份/状态、打开Excel/PDF核对当前授权范围。
5. 总部发布协议价格并生成整月账单；原生登记线下付款→财务独立核验→原生实收记录→申请发票/退款→总部处理→刷新进度。已开票与退款冲突由服务端阻止，不自动冲红或退款。
6. 总部运行周期作业后查看业务待办，打开对应月报/核验/账单；消息已读后原待办仍在，业务完成后才结清。
7. 「集团与服务→合作咨询」填写资料，同意本次联系用途后提交；总部接收/联系/关闭后查看状态和通知，另一访客不能读取旧记录。总部发布内容和FAQ，公众入口查看正式资料、地区网点、公开资料和客服；换另一加盟商账号检查私有报表/账单/申请隔离。
8. 定位仅按钮主动触发；现场照片上传后提交核验；客服在线咨询、正式工单、补充、人工关闭与评价分别验证。

## 验证与环境

已有微信与短信登录适配、账号绑定、支付 SDK 返回后查单、部分草稿、有效版与最新提交版分离、招生待确认、更正字段差异、GPS 精度及采集时间、覆盖率、客服回复确认与隐私指引入口。本轮支付验证使用隔离 Mock 和签名替身。源目录用于本地 development/simulator。真机测试与生产通过 `scripts/wechat-build.cjs` 生成独立包，要求 HTTPS 非回环地址、获准的真实 AppID、开启域名校验并移除开发入口。

V3.3 基线的官方 WXML/WXSS 编译覆盖 19 页。基线在微信开发者工具中已导入，CLI 服务端口关闭，项目作者信任提示阻断模拟器，实测 0/19。全量整改候选待按新 SHA256 独立取证。真机、平台审核和真实渠道联调待验。参见 [V3.3 当前发布状态](../docs/V3.3当前发布状态.md) 和 [微信模拟器实际验证报告](../docs/微信模拟器实际验证报告.md)。

早期 18 页编译、29 项原生测试与 20 个源码转换视图见 [历史原生验证记录](../docs/WECHAT_MINIPROGRAM_VALIDATION.md)。当前原生工程须与同版本服务端契约和迁移共同发布。
