# 九盈英才 V3.3 架构与边界

微信原生小程序与独立总部 Web 共用 Node.js 24 HTTP API 和 SQLite。小程序在 `miniprogram/app.json` 注册 19 个路由，包含 18 个原始业务页面和 V3.3 新增的业务详情页 `pages/service-detail/index`。运行依赖锁定 pdfkit 0.20.2 和 sharp 0.35.5，首次安装执行 `npm ci`。CJK OFL 字体和依赖许可随源码保留。

接入层server/index.cjs负责来源、载荷、认证、requestId与响应；auth.cjs负责scrypt密码、激活、限流、会话版本；repository.cjs负责SQL授权列表/详情，command-scope.cjs只装载命令所需主体/网点/月份；core.cjs/operations.cjs负责确定性状态机；storage.cjs在事务内只保存变化实体；analytics.cjs按所需期间查询当前有效报告和已批准调整。前端不能直接访问库或自授角色。

个人subject与岗位actor分离，staffAccounts保存个人岗位/授权，users和sessions每次校验状态与binding_version。负责人一主体一账号、多网点；区域逐人网点/指标/审核权限；客服只处理本人接单或未分配队列。离任先交接，再撤销旧会话。开发自选角色仅mock且非production；本地密码身份不依赖微信，微信code2session与腾讯短信适配已实现、真实凭证联调仍未完成。

列表默认50/最大200，旧/api/state保留每集合最多200快照以兼容调用者，长列表使用/api/collections。统计totals/partial对应完整授权范围，rows分页；导出超过1000网点明确拒绝。SQL统计不扫描全部旧版报告，但请求周期内有效数据和授权网点仍在内存汇总，不能把10020条历史测试当无限容量承诺。

月报原始版本、当前有效版、汇总调整、统一结算分离。收入用元输入，校验两位小数，汇总转换整数分；金额投影amount_cents对null仍为SQL NULL。缺失、N/A与0不同。更正/撤销使正式结算失效，process使用最新批准版，管理重新结算后才进入settled。

不可变价格版本→协议价格快照→整月账单；停费申请先保留null，明确核算提案经另一自然人财务复核后才抵扣。线下实收、退款申请/批准/外部完成凭证、发票/红票各自保存；批准退款不等于资金已退，系统不调用银行或税务。旧账冲正仍保留并关联新单。未确认部分月、合同期内升降级与转让责任不自动计算。

非test模式使用Asia/Shanghai当前业务日；可信测试时钟可注入。scheduler.cjs按有界批次扫描，持久游标、任务和jobKey，出账按协议日；报告/付款等事实可自动结清待办，已读通知不能结清。外部推送与站内通知分开；未配置适配器拒绝真实操作。

审计链保存内容哈希与前序哈希，能检测已记录内容更改；不是外部签名或不可篡改存储。在线VACUUM INTO备份、完整性/外键/审计链校验及新路径恢复已提供代码和测试，长期运维还需定期演练、异地加密保存与容量监控。

图片由sharp解码、最多2000万像素/单帧、两并发、10秒超时、最长边4096并重编码剥离元数据，最大5MiB；file_metadata记录原始摘要/输出像素/变换版本。不是完整病毒扫描。管理层/api/operations/health返回数值请求/调度指标、quick_check和审计链状态，不能将健康接口当生产合格证明。

SQLite保持单库事务。生产部署前仍需实际硬件/并发容量、文件策略、HTTPS、监控告警和真实平台验收。若切PostgreSQL，另立迁移/对账/双读方案，不将本工程称作已用PostgreSQL。

附件文件与清洗元数据在同一事务提交；异步解码结束后重新校验当前会话，撤权不能继续写入。旧图片在已授权读取时懒清洗，保留原摘要及变换版本。早期 89 项快照记录了回滚与撤权竞态测试。当前证据以 [V3.3 当前发布状态](V3.3当前发布状态.md) 为准。

## V3.1整改增量

external-auth/auth-providers处理外部身份及腾讯短信；wechat-pay仅负责供应商签名/验签/加解密，payments负责幂等、资金事务和订单约束，payment-worker有限查单；official-account负责安全模式入站/回复outbox，official-worker有界发送。任何外部HTTP均不在长数据库事务中等待，返回后重验当前身份；已确认外部资金事实通过独立事务核对后入账。真实平台联调仍未验收。

009—013扩展迁移；内容发布快照/版本、招生适用性历史、负责人历史/身份重置与限时授权同业务记录关联。当前有效月报与最新提交版分离；覆盖率不是零值填充。开发/测试/生产原生包由环境构建器生成，非开发包物理移除开发身份代码，不使用WebView替代原生。
