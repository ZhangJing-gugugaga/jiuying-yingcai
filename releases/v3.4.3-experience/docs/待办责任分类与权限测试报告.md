# 待办责任分类与权限测试报告

测试使用隔离 SQLite、开发身份、真实 HTTP 和 Chrome。测试数据为合成登记。

| 场景 | 核对 |
| --- | --- |
| 四类待办 | 管理层可见 4 类，本地空队列显示 0。卡片计数与对应后端队列一致，点击、刷新、回退及分页保留当前筛选。 |
| 月报责任 | 提交进入运营；退回进入加盟商修改；重提生成新版本和运营任务；收入更正转财务，财务通过后关闭。历史任务保留且只计当前任务。 |
| 总部协作 | 服务费按现有权限由运营提出核算提案，财务独立复核。财务退回后转回运营。已接单的升级客服工单由管理层处理，办理后关闭当前责任。 |
| 角色与授权 | 运营、财务、客服、位置、区域、加盟商各取当前权限。区域审批受审核授权和网点范围约束。调整授权后旧链接和重放按当前权限处理。 |
| 分派与截止 | 总部登记、转派、关闭保留前后岗位与处理时间。转派后旧责任人无法继续办理。有效截止支持日期或带时区时间，业务日跨日、跨月测试及无期限场景均留证。 |
| 联动与一致性 | 原生工作台、待办与消息重提共享持久化任务。消息已读状态与业务关闭独立。原有效版在更正审批期间继续展示。 |
| 持久化与升级 | 旧任务 ID 与历史保留。重复命令、并发写入、唯一约束、无网点的新网点申请、结算和客服配置分别回归。 |

责任结构、访问与重放分别见 [责任队列测试](../tests/v32-responsibilities.test.cjs)、[区域授权重放测试](../tests/v32-replay.test.cjs)、[小程序与总部联动测试](../tests/miniprogram-v3.test.cjs)。结果和日志见 [测试证据](../execution/V32_TEST_EVIDENCE.md)。

月度总览 Chrome 记录六个不重复的经营周期查询。容量脚本使用 3,600 条当前任务与 3,600 条历史任务，八并发共 120 次 HTTP 请求，逐次校验总览计数、筛选、权限和分页，结果保存在 [合成容量报告](../execution/v32-load.json)。生产容量以目标环境测试为准。
