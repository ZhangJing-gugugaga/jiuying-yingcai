# 九盈英才 V3.3 财务汇总与对账验证报告

## 结论

D02、D05、D09 的源码整改已通过本地 SQLite、鉴权 HTTP、总部 Chrome 及原生页面逻辑验证。验证使用隔离数据库和测试凭证。正式合同、生效及关闭月规则、真实支付清算和财务验收留待集团确认。

## 财务口径

| 指标 | 服务端计算 | 历史账单处理 |
| --- | --- | --- |
| 应收 | 有效账单当前确认的净应收，整数分汇总 | 冲正旧单的原面额保留在详情，当前应收由有效新单贡献 |
| 累计实收 | 同一账单、同一网点和主体的全部成功实收流水 | 保留冲正旧单实际发生的收款 |
| 已退款 | 关联同一张账单的成功实收，且状态为已登记的退款 | 已审核但未记账的退款不进入此项 |
| 净实收 | 累计实收减已退款 | 原账单全额退款时净实收为零 |
| 未收 | 状态为待支付的账单，金额扣减已记净实收，最小为零 | 已付账单发生退款后保持原支付状态，沿用现有规则 |
| 逾期 | 上海当前业务日已过账单明确截止日的未收 | 补账保留协议原截止日，缺失截止日的旧单继续显示未收 |
| 待核算调整 | 按授权范围统计待核算笔数，月份筛选匹配暂停期间 | 有待确认金额时金额为空，另列金额未确定笔数 |

按账单自然月追溯收款与退款，展示截止查询时点累计数据。退款发生月与经营收入报表的财务归期继续待集团确认。CSV 使用与详情相同的整数分计算口径，导出列使用固定两位小数。导出附运行环境及汇总行，服务器记录导出人、范围、版本和请求编号。单次 CSV 最多 10,000 账单，可按月或网点缩小范围。

## 服务接口与权限

| 入口 | 参数 | 权限与输出 |
| --- | --- | --- |
| GET /api/finance/summary | 可选 month、owner、outlet、limit、offset | 管理层、财务和加盟商本人。全范围 totals，网点列表分页 |
| GET /api/finance/bills/{id} | 可选 section、limit、offset | 同一财务范围。账单主体与金额、冲正链、调整来源和各类凭证分页 |
| GET /api/finance/export | 可选 month、owner、outlet | 同一财务范围。CSV 账单明细和同口径汇总 |
| GET /api/finance/catch-up | 可选 month、owner、outlet、status、limit、offset | 管理层、财务。补账待复核清单与已处理历史 |
| GET /api/collections/bills 或指定账单 | 沿用已有合同 | 管理层、财务及加盟商在账单上收到新增 ledger。运营保留原有应收视图 |

月份为 YYYY-MM。分页 limit 默认 50，范围 1–200，offset 默认 0。详情 section 可以是 receipts、payments、offlinePayments、refundRequests、invoiceRequests、lineage、credits 或 corrections；offset 作用于所选分类，其他分类返回首页。补账状态支持 pending、handled 和 all。加盟商越权账单详情返回 404，越权网点范围返回 403。总部 Web 服务费管理提供账务汇总、网点筛选、分页凭证、冲正链及 CSV。原生小程序咨询服务费页可进入全部网点钱包汇总、单网点账务和指定账单。

## 自然月追补与原账冲正

- 调度按照上海自然月保留现行协议出账，补扫已知漏账区间。本次首次运行以前的追补可用 BILLING_CATCHUP_FROM_MONTH 声明经确认的最早月份。留空时，读取已存在的调度月份或首个观测月份作为历史范围。范围以合同记录约束，并按账期及协议游标分页。
- 历史补账仅自动处理有明确整月版本、账期前已登记协议且覆盖完整营业月的期间。历史协议首末月份、筹备、部分月、关闭月及营业记录不完整期间进入人工复核，记录请求编号及原因。当前协议首月缺少账期前登记或营业证据时也进入复核。存在待财务核算调整时保留阻塞并随批次复核。曾生成或冲正的账期不会重复出账。
- 冲正沿用独立发起、财务复核和退款/票据凭证门槛。保留旧账单、支付、退款、原抵扣与开票记录。新账单继承能确认的合同号及服务、收款、开票主体，关联根账单和更正单；由财务确认新账净应收，原抵扣仍指向其实际应用的旧账单。待确认的更正后毛额保存为空。旧版存量中当时未记录的字段可能仍为空，可沿链查看原合同与账单。
- 迁移 017 新增账单和凭证索引、补账复核表，不重写历史数据。已有单账单最终实收唯一约束继续生效。需要回退时先关闭调度，保留索引和已处理记录；发布前在生产库副本测量索引建表窗口。数据库额外成本主要为新增索引写入、复核记录与查询，链路没有新增外部服务成本。
