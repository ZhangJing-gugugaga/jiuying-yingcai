## 数据、文件与发布方式

- `miniprogram/pages/report`、`miniprogram/pages/reports`、`miniprogram/pages/home` 和 `miniprogram/utils/page.js` 处理交互、状态和跳转。待办、消息、看板、账单、协议、位置与安全页清理了技术文案。
- `shared/core.cjs`、`server/repository.cjs`、`server/analytics.cjs` 增加月报资格和结算提示的读取字段。历史通知仍按请求和月报权限读取。新通知额外存储网点月报标识和月份。
- 先部署后端再发布小程序。API 新字段为增量扩展，旧小程序可继续读取原字段。当前小程序遇到未提供新的资格字段的后端会显示只读状态。沿用现有 SQLite 结构和财务统计口径。
- 工作台增加一次按权限查询 SQLite 历史结算，月报详情增加一次带范围索引的免报查询。首页无额外 HTTP 请求。没有新增运行依赖或第三方费用。
