## 人工复核

1. 用访客账号从登录进入网点 Tab。检查公开列表、地区筛选、地图标记、无坐标空态、地址复制，再从工作台或我的进入集团与客服。月报 Tab 应显示账号登录提示。
2. 用有权限的加盟商账号从工作台进入我的网点。比较有月报、免报、无账单及已结清网点的状态与账期。通过集团入口查看已发布的其他加盟商网点，再返回我的网点。确认公开地图、地址、详情都与已发布资料一致。
3. 在位置核验分别操作拒绝权限、现场定位、地图选点、切换网点或月份。检查照片、定位精度、采集时间和核验历史。用预置测试数据核对退款各阶段及凭证来源。
4. 在同一最终候选工程中按表复核剩余路由、空态、错误重试、窄屏布局和返回路径。实际请求及截图记入微信模拟器报告。
