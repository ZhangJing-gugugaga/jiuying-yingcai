# 九盈英才 V3.3 前端待产品确认功能清单

| 问题 | 当前用户路径 | 待确认或依赖 |
| --- | --- | --- |
| GAP-02 位置核验逾期 | 显示真实核验记录。当期符合申请条件且缺记录时提示“等待提交”。 | 集团需确认核验截止时刻、豁免和逾期转办。确认后由服务端产生逾期状态和总部任务。 |
| GAP-03 业务申请预计恢复日期与附件 | 暂停营业原因可说明预计恢复日期。证明材料通过总部既有沟通渠道补充。 | 结构化日期与上传需确定写入字段、附件种类及大小、权限、审批查阅、留存与审计。负责人或手机号变更的证明规则待集团确认。 |
| GAP-04 客服工单和材料 | 投诉、售后问题、经营异常可提交工单。网点、费用和其他问题可通过在线咨询联系总部。已有工单支持文字补充。 | 确认正式类别、附件、客服电话和工作时间、工作日历 SLA、严重投诉标准及消费者与加盟商队列和脱敏规则。 |
| GAP-05 地图运行时服务 | 当前使用微信 `wx.getLocation`、`wx.chooseLocation` 和原生地图组件，地图选点作为地址辅助。 | 高德 MCP 可用于开发资料查询。若产品需要高德 POI、地址解析或地理编码，需明确集团授权、服务端 Key 存储、额度成本和接口。现场 GPS 偏差、精度与照片留存由集团另行确认。 |
| GAP-07 支付宝原生能力 | 微信原生小程序展示可用的微信付款和已有支付宝交易历史记录。 | 支付宝 WAP 收银台与支付宝原生小程序是不同渠道。新增支付宝小程序需另行确定服务范围、支付资质和发布路径。 |
| GAP-08 外部资金与税务 | 继续使用现有线下付款登记、财务核验、退款流程和发票申请。页面按真实审批、渠道或人工登记证据展示。 | 银行划款、税务开票与无需人工批准的自动退款仍无产品链路。正式渠道凭证联调、财务授权和制度另行确认。 |
| 公开内容和平台验证 | 服务网点、五大业务、客服资料及 FAQ 使用总部发布结果。 | 总部提供正式内容、图片使用授权、公开地址坐标、联系电话和服务时间。微信平台授权、设备、测试账号及发布检查由正式验收补齐。 |

公开目录和加盟商网点状态摘要已进入本轮整改，后续正式数据与微信运行验证见逐页体验和模拟器报告。月报、合同、停费、抵扣、历史权限与财务口径的制度条目见 `PENDING_DECISIONS.md`。
