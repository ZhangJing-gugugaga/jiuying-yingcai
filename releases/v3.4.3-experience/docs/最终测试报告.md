# 最终测试报告：报告入口与证据口径

本文件随可编辑源码提供复验方式。该 ZIP 的实际结果、完整输出和最终 SHA256 在同交付目录的《最终测试报告.md》《重新解压验包记录.json》《SHA256文件清单.txt》。ZIP 内不声称自己已通过尚未执行的独立运行，也不在 ZIP 里嵌入自身散列。

| 验证层 | 本轮复验命令或证据 | 覆盖范围 |
|---|---|---|
| 本地全量 | `npm ci`、`node scripts/check-syntax.cjs`、`node database/migrate.cjs`（两次）、`node --test tests/*.test.cjs` | 使用隔离 SQLite 和既有以及新增测试；保留原有断言 |
| 总部 Chrome | `tests/browser*.cjs` 中八套回归 | 总部网页和本地后端，不代表小程序 |
| 微信静态验证 | `node scripts/wechat-validate.cjs` | 原生工程、路由、文件和绑定 |
| 官方编译 | `node scripts/wechat-compile.cjs --tool-dir <官方开发者工具目录>` | 官方 WXML/WXSS 编译器，结果不等同于 IDE 实际编译或模拟器交互 |
| 生产包剥离 | `node scripts/wechat-build.cjs --environment production --target device --api-base https://example.invalid --app-id wx0000000000000000` | 占位参数仅验证构建，不向该域名发请求，不是可发布包 |
| SQLite | `node scripts/backup.cjs create / verify / restore` | 仅本机隔离库和隔离输出 |
| 微信 IDE / 模拟器 | `最终候选微信实测证据/`、外部逐页表、原始 CLI/界面记录 | 仅同一 SHA 的实际观察，不推算页面通过 |
| 真机、真实服务、生产、甲方 | 单列，不计入隔离测试结果 | 集团授权、凭证、正式制度、部署容量和验收未完成 |

统一执行入口：在全新发布候选目录配置官方开发者工具 `WECHAT_DEVTOOLS_PATH` 后，运行 `py -3 scripts/package.py`。脚本会保留候选日志并拒绝发布验证失败的候选。
